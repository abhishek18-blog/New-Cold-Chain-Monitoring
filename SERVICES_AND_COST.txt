TOTAL CLOUD RUN DEPLOYMENTS : 5
  ├── Cloud Run Services (always-on HTTP containers) : 3
  └── Cloud Run Jobs (batch / cron-triggered)        : 2

────────────────────────────────────────────────────────────────────────────────
SERVICE 1 — coldchain-dashboard-api   [Cloud Run SERVICE]
────────────────────────────────────────────────────────────────────────────────
  Role       : Public-facing Operations UI + REST API
  Image Dir  : ./dashboard
  Port       : 8000
  Ingress    : INGRESS_TRAFFIC_ALL  (public HTTPS)
  CPU        : 1 vCPU   (cpu_idle = true — scales to 0 when no traffic)
  Memory     : 1 Gi
  Scaling    : min=1  to  max=5 instances
  Endpoints  : /api/trucks  /api/alerts  /api/metrics
  Tech       : FastAPI + Leaflet.js map + WebSocket live KPIs
  Visibility : Public (allUsers invoker binding)

────────────────────────────────────────────────────────────────────────────────
SERVICE 2 — coldchain-processor   [Cloud Run SERVICE]
────────────────────────────────────────────────────────────────────────────────
  Role       : Real-time stream processor (telemetry -> excursion classification)
  Image Dir  : ./processor
  Port       : 8080 (internal)
  Ingress    : INGRESS_TRAFFIC_INTERNAL_ONLY
  CPU        : 1 vCPU   (cpu_idle = FALSE — always-on, zero-lag processing)
  Memory     : 512 Mi
  Scaling    : min=1  to  max=10 instances
  Consumes   : Pub/Sub subscription "telemetry-sub"
  Publishes  : Pub/Sub topic "alerts-topic"  (on excursion)
  Writes To  : Firestore collections — live_status & alerts
  Logic      : Schema validation, temp/humidity threshold checks (OK/WARN/CRIT),
               out-of-order timestamp guard, DLQ routing (5-retry poison pills)

────────────────────────────────────────────────────────────────────────────────
SERVICE 3 — coldchain-alert-notifier   [Cloud Run SERVICE]
────────────────────────────────────────────────────────────────────────────────
  Role       : Driver & fleet-ops alert dispatcher
  Image Dir  : ./alert-notifier
  Port       : 8080 (internal)
  Ingress    : INGRESS_TRAFFIC_INTERNAL_ONLY
  CPU        : 1 vCPU   (cpu_idle = FALSE — instant alert dispatch)
  Memory     : 512 Mi
  Scaling    : min=1  to  max=3 instances
  Consumes   : Pub/Sub subscription "alerts-sub"
  Channels   : Discord Webhook, SMS/WhatsApp simulation, in-cab buzzer downlink
  Logic      : Driver directory lookup, 15-min anti-spam debouncer per truck

────────────────────────────────────────────────────────────────────────────────
SERVICE 4 — coldchain-silence-detector   [Cloud Run JOB + Cloud Scheduler]
────────────────────────────────────────────────────────────────────────────────
  Role       : Detects dead/offline trucks (NO_SIGNAL flag)
  Image Dir  : ./silence-detector
  Job Type   : Cloud Run v2 Job  (runs once per invocation)
  Trigger    : Cloud Scheduler cron  "* * * * *"  (every 1 minute)
  CPU        : 1 vCPU   (batch — no HTTP server, exits after scan)
  Memory     : 512 Mi
  Logic      : Scans Firestore live_status; flags trucks whose last_updated
               timestamp is older than 120 seconds as status=NO_SIGNAL
  Env Vars   : RUN_ONCE=true, SILENCE_CHECK_INTERVAL_SEC=30,
               SILENCE_TIMEOUT_SEC (configurable, default 120s)

────────────────────────────────────────────────────────────────────────────────
SERVICE 5 — coldchain-telemetry-generator   [Cloud Run JOB]
────────────────────────────────────────────────────────────────────────────────
  Role       : Simulated IoT fleet data producer (15 refrigerated trucks)
  Image Dir  : ./telemetry-generator
  Job Type   : Cloud Run v2 Job  (manually triggered or on-demand)
  CPU        : 1 vCPU
  Memory     : 512 Mi
  Publishes  : Pub/Sub topic "telemetry-topic"
  Config     : PING_INTERVAL_SEC=1.0, EXCURSION_PROBABILITY=0.03
  Trucks     : TRK-001 through TRK-015 — GPS routes, temp, humidity,
               speed, fuel %, door status, vibration

  BIGGEST COST DRIVER:
    -> processor & alert-notifier each have cpu_idle=FALSE with min=1 instance.
       They consume a full vCPU 24x7.  Combined that is ~$100-140/month alone.

  COST OPTIMIZATION TIPS:
    1. Set cpu_idle=TRUE on processor/alert-notifier if sub-second latency is
       not required — this can cut Cloud Run bill by up to 90%.
    2. Reduce min_instance_count to 0 (scale-to-zero) if cold-start delay
       of ~1-2 seconds is acceptable.
    3. Reduce Firestore write frequency (batch updates every 15s instead of
       every message) — can cut Firestore cost by 60-70%.
    4. Partition BigQuery queries to minimize scanned bytes.
